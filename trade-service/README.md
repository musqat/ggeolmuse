# Trade Service

주식 거래 및 포트폴리오 관리 서비스

## 주요 기능

- 주식 매수/매도 주문 실행
- 포트폴리오 조회 및 평가액 계산
- 보유 종목(Holdings) 관리 (FIFO 방식)
- 배당금 자동 지급 및 재투자
- 거래 내역 조회 및 통계

**의존 서비스:** User Service, Market Data Service
