# Market Data Service

주식 시세 및 배당 데이터 수집/제공 서비스

## 주요 기능

- 11,000+ 미국 주식 종목 데이터 관리 (NYSE, NASDAQ, NYSE ARCA)
- 20년치 일별 OHLC 데이터 수집
- USD/KRW 환율 데이터 수집 및 제공
- 배당금 정보 수집 및 제공
- 데이터 소스 이원화 (Alpha Vantage, Yahoo Finance 전환 가능)
- 실시간 시세 조회 (캐싱 활용, Hit Rate 77%)

**의존 서비스:** Alpha Vantage, Yahoo Finance
